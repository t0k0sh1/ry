# Changelog

- Do not edit `CHANGELOG.md` directly for normal feature/fix work.
- User-visible changes use `changelog.d/<issue>-<slug>.md` with a Keep a Changelog heading (`### Added`, `### Changed`, `### Fixed`, or `### Removed`) and an issue/PR reference.
- Direct `CHANGELOG.md` edits are only for `/preparing-for-release` aggregation, release promotion, and comparison-link updates.
- For skip conditions and verification, see `/pre-commit-checklist`.
