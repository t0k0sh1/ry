# Security Policy

## Supported Versions

Only the latest release is supported with security updates.

| Version | Supported          |
|---------|--------------------|
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it through [GitHub's Private Security Advisory](https://github.com/t0k0sh1/ry/security/advisories/new).

**Please do not open a public issue for security vulnerabilities.**

### What to include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### Response timeline

- **Acknowledgement**: within 3 business days
- **Assessment**: within 7 business days
- **Fix release**: as soon as practical, depending on severity
