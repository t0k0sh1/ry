### refactor(codegen): migrate stdlib op follow-on (split/replace/substr + args/range/input/env/isEmpty) via crates/emit primitives (#2192)

Follow-on sweep settling #2096's "Settle ≠ unlock" cluster outside the string-build family. Eight stdlib codegen emitters — `emitStrOp_split` / `emitStrOp_replace` / `emitStrOp_substring` (`src/codegen_call_string.cpp`) and `isEmpty` / `args` / `input` / `env` / `range` (`src/codegen_call.cpp` `emitBuiltinQuery` branches) — drop their remaining `builder_.Create*` calls in favor of the existing `ry_emit_*` primitive vocabulary. One new generic primitive `ry_emit_sext` (`LLVMBuildSExt`, symmetric partner of `ry_emit_zext`) is added in four layers for `args()`'s i32→i64 argc widening; `CreateNeg` in `range()` rewrites to `emitSub(zero, x)` (LLVM-internally identical IR) so no `ry_emit_neg` primitive is needed. Carve-outs (variadic `emitRuntimeError`, regex abort paths in split/replace, `arc_str_owned_values_` / `arc_owned_values_` decision sets, `emitArcAllocCollectionHeader`, `storeListHeaderFields`, `setTypeMeta`, `wrapPtrAsOption` / `emitResultBranch` composite helpers, `used_native_libraries_.insert("io")`) stay C++-side by design. ASLR-normalized `--emit-llvm-ir` diff is empty over the eight `tests/filecheck/*_parity.ry` probes; `input`'s 0-arg `__ry_io_read_line` overload and `substr`'s constant-index fast path are each covered by a dedicated probe so per-call-site arg-list typos cannot pass an empty diff. `ry_tests` (2795) and `ry test -p` (207 spec files) stay green. The eight public Ry-level APIs' shapes are unchanged.
