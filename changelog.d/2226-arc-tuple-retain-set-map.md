### fix(codegen): retain tuple inner-ARC components on Map merge + Set ops (#2226)

`Map<K, (..., List<T>, ...)>` merge and `Set<(..., List<T>, ...)>` construction (`union` / `intersection` / `difference` / `symmetricDifference`) previously skipped retain on tuple-typed entries because their `ptrTy_`-gated ARC checks miss inline tuple `StructType`. Dropping the source map/set after the operation then freed the inner List/Map/Set buffers the result still referenced (UAF; reproducible via the new `tests/spec/arc_set_map_tuple_2226.test.ry` detector). The fix mirrors the appended-list tuple retain pattern (#1667): Map merge's memcpy / update / insert paths and all four set-op functions now emit `emitTupleElemRetainLoop` / `emitTupleComponentRetain` (and Set ops additionally pick up the previously-missing flat-ARC retain for `Set<List/Map/Set>` element shapes). Destructor-side tuple-recursive release was already wired (#1667) so symmetry is restored.
