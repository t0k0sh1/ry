### refactor(emit): align `abi/result.rs` resolve callers with the `resolve_value` guard pattern (#2251)

The three value-id resolutions in `crates/emit/src/abi/result.rs` — `is_err` (former `line 80`) and the two `build_ok` / `build_err` closure bodies (former `line 95` / `101`) — were the last `resolve(c, id)` callers in the abi layer without the `resolve_value(c, id)` + `let Some(...) else { return 0 }` defensive guard shared by every other entry point (`bounds.rs:48`, `arc.rs:48`, `any.rs:93`, `cow.rs:67`, `reduce.rs:37`, …). On a sentinel-0 / out-of-range `is_err_id` the raw `resolve` would feed a NULL condition to `LLVMBuildCondBr`, and a callback returning `0` would yield a NULL PHI incoming — both LLVM-asserting / verify-rejecting paths. `ry_emit_result_branch` now resolves `is_err` via `resolve_value` and short-circuits to sentinel 0 before any BB is appended, and the do_ok / do_err closures' return type changed from `ValueRef` to `Option<ValueRef>` so a `None` resolution after a re-entrant callback propagates up through `composite::result::emit_result_branch` — which gained a matching `&mut dyn FnMut() -> Option<ValueRef>` signature and returns `ValueRef(null_mut())` on `None`, the same NULL channel the existing `insert_bb.is_null()` guard already used — to the abi shell's `intern(NULL) → 0`. The two-step `with_ctx` re-entrant-borrow discipline (#2069 / #2081) is preserved: each callback is still invoked outside any `with_ctx` and its returned id is resolved inside a fresh `with_ctx` scope. Two new direct regression tests in `tests/test_emit_abi_guards.cpp` (`ResultBranchUnresolvedIsErrIdReturnsZero`, `ResultBranchCallbackReturningZeroReturnsZero`) lock in the new sentinel behavior, set a real insert block so the `composite::result::emit_result_branch`-internal NULL-block guard is not the gate, and complement the existing `ResultBranchNullCtxReturnsZero` / `ResultBranchNullCallbacksReturnsZero` coverage. ASLR-normalized `--emit-llvm-ir` diff is empty across `examples/result_propagation.ry` (the `?`-operator path) and `examples/file_io.ry` (the `io.{readText, writeText}` `Result`-destructuring path); `ry_tests` (2805) and `ry test -p` (208 spec files) stay green.
